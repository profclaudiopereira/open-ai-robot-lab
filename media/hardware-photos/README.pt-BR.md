# Fotos dos Componentes

Esta pasta contém fotografias reais dos componentes utilizados no projeto Open AI Robot Lab.

## Objetivo

Estas fotos são utilizadas para:
- documentação de hardware
- tutoriais educacionais
- referências do BOM
- explicações de wiring
- guias de montagem
- documentação arquitetural

## Componentes

- ESP32-S3 Super Mini
- Microfone INMP441 I2S
- Amplificador MAX98357
- Display OLED SSD1306
- Módulo TP4056
- Bateria Li-ion 3.7V
- Speaker
- Módulo SD Card

Todas as imagens foram capturadas a partir do hardware real do projeto.

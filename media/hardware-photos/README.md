# Hardware Photos

This folder contains real photographs of the hardware components used in the Open AI Robot Lab project.

## Purpose

These photos are used for:
- hardware documentation
- educational tutorials
- BOM references
- wiring explanations
- assembly guides
- architecture documentation

## Components

- ESP32-S3 Super Mini
- INMP441 I2S Microphone
- MAX98357 Audio Amplifier
- SSD1306 OLED Display
- TP4056 Charging Module
- 3.7V Li-ion Battery
- Speaker
- SD Card Module

All images were captured from real project hardware.

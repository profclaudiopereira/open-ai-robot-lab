# Open AI Robot Lab

Build • Learn • Evolve

一个专注于以下方向的开源教学实验室：
- 人工智能
- 语音接口
- ESP32 机器人
- 混合 LLM 架构
- 嵌入式系统
- 3D 打印机器人

## 主要硬件

- ESP32-S3 Super Mini
- INMP441 I2S 麦克风
- MAX98357 音频放大器
- SSD1306 OLED 显示屏
- TP4056 充电模块
- 3.7V 锂电池

## 项目目标

- 分阶段教学
- 渐进式开发
- 多语言文档
- OpenAI 与本地 LLM 对比
- 可 3D 打印机器人平台

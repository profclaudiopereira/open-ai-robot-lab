
# Fase 0 — Foundation Setup

## Objetivo

Preparar o ambiente de desenvolvimento e validar as primeiras conexões de hardware.

## Objetivos de Aprendizagem

- Conceitos básicos do ESP32-S3
- Programação via USB
- Monitor serial
- Teste do OLED
- Entrada por botão
- Organização do repositório

## Componentes Necessários

- ESP32-S3 Super Mini
- Cabo USB-C
- Display SSD1306 OLED
- Protoboard
- Jumpers

## Entregáveis

- Upload de firmware realizado
- OLED funcionando
- Primeiras mensagens de debug

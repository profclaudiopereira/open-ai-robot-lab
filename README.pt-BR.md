# Open AI Robot Lab

Build • Learn • Evolve

Laboratório didático open source focado em:
- IA
- Interfaces por voz
- Robótica com ESP32
- Arquiteturas híbridas com LLM
- Sistemas embarcados
- Robótica com impressão 3D

## Componentes Principais

- ESP32-S3 Super Mini
- Microfone INMP441 I2S
- Amplificador MAX98357
- Display OLED SSD1306
- Módulo TP4056
- Bateria Li-ion 3.7V

## Objetivos do Projeto

- Aprendizado didático passo a passo
- Evolução progressiva sem quebrar fases anteriores
- Documentação multilíngue
- Comparação OpenAI + LLM Local
- Plataforma robótica imprimível em 3D
